Ramble page maps

Each map is a render tree of one page group, traced from the code on main: every component from the layouts down, marked server, cached, streamed or client island, with the actions it calls and how its caches are cleared. Each map's footer names the commit it was read from.

The hold, payment start, the webhook that confirms.

Status polling, the receipt, guest changes.
