## Tonight's experiments

### A1106-1 (type C, tooling): `tools/day-cost.py` prices the local day in one call

- **Finding:** 11-03 finding 1, the cost window, recurs every night. `token-audit --yesterday` counts the UTC day (its own help says "Calendar yesterday UTC"), so each night's figure takes in the previous evening's lane chats and misses the day's own evening, and each night's review reconciles it by hand. Tonight that took 11 calls: the three `--yesterday` views, then a `--session` drill-down on each of 7 sessions to find that all of them ended on 11-04 evening, then a check of `--today`. Last night's local figure ("about $224") was an estimate built the same way.
- **Change:** new file `tools/day-cost.py`, 32 lines. It loads token-audit's own `parse_logs` and price table (read only, nothing in `~/.claude` changes) and counts local midnight to midnight in New York with the same `ramble` project filter. It prints the total, calls and sessions, then the top 10 by agent, by model and by session, each session with its first and last local call time.
- **Metric and target:** the local-day cost by agent, model and session in one call, matching a hand reconciliation, in place of the 3 token-audit views plus the drill-downs.
- **Test:** on 2026-11-05 it prints $28.77, 416 calls, 2 sessions: 397ece22 $24.71 and 010d3c48 $4.06, which is exactly the hand reconciliation (the same two sessions' `--yesterday` costs, every call of both on the local day). On 2026-11-04 it prints $213.43 over 20 sessions; last night's hand estimate was about $224 including $8.37 for daf687ac, which neither tool sees under the project filter, so the two agree within about $3 on what they both count. On the baseline day 2026-10-29 it prints $430.19 over 14 sessions; the baseline's $580 came from `--since 2026-10-29` run the next day, a longer window, so it is not a one-day figure. It runs in about 8 seconds (the same parse token-audit does) and its output is 0.8K characters. Calls for tonight's cost section: 11 by hand against 1.
- **Known limit:** the `ramble` project filter still misses chats whose cwd is not under a ramble path (daf687ac on 11-04); that is token-audit's filter, unchanged.
- **Result: passed.** Published with tonight's commit. Revert: `git rm tools/day-cost.py`. The nightly task's prompt (owner only) could use it in place of the three `--yesterday` views in Step 1.
