Ruled out: barrels (`Chip`, `Button`) are not a problem; the header, shell and site menu are already server components; `Button`'s `use client` costs under 1 KB; the drawer warm-up runs after hydration and does not lengthen the dead window.

Best case: JS-1, 2, 4 and 5 take browse to about 155-160 KB, 20-23% less, about 0.2-0.25 s off the 1.4 s Slow 4G window (inferred, assuming about 200 KB/s). Trimming cannot close the window: the framework alone is about 0.7 s.

Not-ready state for Filters, Neighborhood and Guests: stopgap only. A static style would flash on fast visits, so it needs a CSS animation delayed 300-500 ms and cancelled at hydration. Use a spinner or underline pulse, not dimming, which can fail contrast. Only `aria-disabled`, never disabled from CSS. Not needed if JS-2 ships.
