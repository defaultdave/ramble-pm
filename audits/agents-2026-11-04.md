## Tonight's experiments

### A1105-1 (type C, tooling): `session-profile.py --now` reads the running chat's context

- **Finding:** the PM file says "You cannot see your own token count, so count these instead." That is no longer true: every chat has `CLAUDE_CODE_SESSION_ID` in its environment, and its transcript records the context of every model call.
- **Change:** `tools/session-profile.py`, +22 lines. `--now` finds `~/.claude/projects/*/<session>.jsonl`, reads the usage on the latest assistant entry, and prints `context <N>K, hand-off line 250K: HAND OFF` or `under the line`. It reuses the file's `records()` and `context()`. If no session id is set, it prints one line and exits 1.
- **Metric and target:** the PM can read its real context in one command, of under 100 characters, without an extra turn.
- **Test:** on this chat it read 161K (the transcript's own last value). With recorded transcripts it read 38609426 at 354K (its final value), 47caf2bd at 127K (after its compaction; peak 738K) and 9be20418 from the baseline day at 893K. It runs in 0.05 s on an 8.6 MB transcript. With the variable unset or unknown, it prints one line and exits 1. The day mode's output for 2026-11-04 is byte-identical to the old tool's. Before, there was no way to read it; the counts the PM uses instead fire at 300K to 511K.
- **Result: passed.** Published with tonight's commit. Revert: `git revert` that commit's `tools/session-profile.py` hunk.

### A1105-2 (type B, trial): hand off at 250K measured context

- **Finding:** see A1102-1 above. Each PM call costs the whole context, and 5 of 12 PM chats ran past 290K before any count fired.
- **Change:** `.claude/agents/ramble-pm.md` line 38, one line. Hand off also when `python3 -I tools/session-profile.py --now` (in `ramble-pm`) prints `HAND OFF`. The command is added to a Bash call the chat is already making, each time an agent result lands and before the next launch, so it costs no extra turn. The counts stay; the sentence "You cannot see your own token count" goes.
- **Metric and target:** PM chats with a peak over 300K: 0 (before: 5 of 12 on 11-04). Compactions per PM chat: 0, the A1102-1 target. Judged after three nights.
- **Test:** this cannot be replayed overnight. Back-test on the recorded transcripts, with a hand-off at 250K, each new chat starting at its first context plus 15K, and 8 start-up calls added per hand-off: 2026-11-04, main-chat context tokens 394M to 271M (31% less) over 12 chats, with 47caf2bd needing 4 hand-offs and falling to 43% of its tokens; 2026-10-29 (baseline), 782M to 352M (55% less) over 10 chats. On 11-04 that is worth about $45 of the $153.60 orchestrator cost.
- **Result: shipped as trial.** PR 906, branch `pm/agent-exp-2026-11-05-2`; `scope-manifest` fails by design, and no auto-merge is queued. Merge: `gh pr merge 906 --repo defaultdave/ramble --merge --admin`. Revert: restore the line's old ending, "whichever comes first. You cannot see your own token count, so count these instead."
