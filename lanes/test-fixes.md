(3) Builders must run `pnpm format:check`: W9b's first head failed CI on a prettier wrap. (4) A reviewer once returned the single word 'placeholder': reject and resume it. (5) After a merge of `main` into a branch, checks must be posted again on the new head, and a rerun of a pull_request job reuses the old merge commit (a stale red `format:check` stayed on every open PR until each branch was refreshed). (6) Shared Postgres: run every `pnpm test:db` under `lockf -k /tmp/claude/ramble-testdb.lock` (fixed path), or 5 builders and reviewers exhaust it (FATAL 53300). (7) Shell: zsh does not word-split a loop variable (use `case`), macOS has no `timeout`, and `agent-git.ts pr` takes the current branch, so run it from the unit worktree. (8) Sandbox: `git worktree prune/remove` of scratch worktrees needs the bypass.
